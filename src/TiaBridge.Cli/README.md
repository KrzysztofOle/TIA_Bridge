# TiaBridge.Cli

Planned home for explicit user commands over core workflows.

Project-modifying commands need a reviewed bounded plan or a valid scoped test-session grant, fresh identity and the safeguards in [the interface design](../../docs/05_CODEX_INTERFACE.md). A grant may cover multiple approved steps; file save and Git changes never authorize import. CLI submits asynchronously and returns an operation ID by default. No CLI implementation exists yet.
